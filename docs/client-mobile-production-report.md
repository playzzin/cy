- 현재 로그인 계정은 팀원 승인 목록 조회 자격을 통과하지 못했다. 자격이 있는 실제 팀장 계정의 목록 조회는 별도 확인이 필요하다. 서버 권한·승인 처리는 데모 에뮬레이터에서 검증했다.

- 검수에 사용한 화면 크기 설정은 원래 상태로 복원했다.
- 브라우저 검수 중 업무 상태를 바꾸는 동작은 실행하지 않았다. 브라우저 자동화 연결에서 네트워크 쓰기 차단의 지속 적용을 입증하지 못했으므로, 기존 앱의 접속 기록·마지막 접속 시각 자동 갱신까지 없었다고 보증하지 않는다.
