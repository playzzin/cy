# 전체 라우트 디자인 적용 목록

`src/App.tsx`의 실제 JSX Route에서 자동 추출. 운영 DB 메뉴 활성 여부는 조회하지 않았으므로 활성 라우트의 상한 목록이다. 공통 shell을 사용하지 않는 공개 페이지와 출력·캡처 문서는 기존 규격을 유지한다.

2026-10-16 실제 전체 앱과 로컬 Firebase 합성 사무실 계정으로 312개 경로×390/1366px=624개 조건을 진입·캡처했다. 감지된 런타임 예외·문서 전체 가로 넘침·보이는 조작 요소의 잘림은 0건이다. 표 내부의 의도된 스크롤은 허용한다. 수정과 관련된 39종 화면은 캡처로 추가 검토했다. 모든 기능·데이터·권한 상태의 검수 완료를 뜻하지 않는다. 로그인·팀장 승인·정산은 별도 업무 흐름으로 확인했다.

원본 근거: `artifacts/client-workflow-qa/route-results.json`. 자동 `unavailable` 42조건에는 정상 안내 문구와 로컬 서비스 제한이 함께 포함되므로 실패 건수로 해석하지 않는다. 각 행에 경계와 두 폭의 캡처를 연결했다. [전체 검수 기록](./client-mobile-workflow-implementation-report.md).
