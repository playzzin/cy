# CY 문서 Vault

이 폴더는 CY 프로젝트의 Obsidian Vault이자 Git으로 관리되는 운영·개발 문서 저장소다.

- Obsidian에서 이 `docs` 폴더를 **Open folder as vault**로 연다.
- 시작 문서: [[00-CY 운영 홈]]
- 개발 최상위 기준: [[../개발지침|개발지침.md]]
- 코드·설정과 문서가 충돌하면 라이브 코드와 `개발지침.md`를 우선하고 문서를 갱신한다.
- 주민등록번호, 계좌번호, 비밀번호, 토큰, 서비스 계정, 개인별 급여 원본은 기록하지 않는다.
- 실제 업무 상태는 CY Todo 또는 GitHub Issues에서 관리하고, 이 Vault에는 규칙·절차·결정 이유를 남긴다.
