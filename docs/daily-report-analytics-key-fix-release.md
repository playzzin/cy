# 일보 통계 Gemini 키 오류 수정 반영 기록

2026-09-28. 사용자가 보고한 “저장된 Gemini API 키가 유효하지 않습니다” 오류에 대한 작업 기록이다.

## 확인 결과

- 해당 오류는 기존 `일보 통계 → AI 분석`의 `geminiAnalyticsService`에서 생성한다. 이 서비스는 서버 설정과 별도로 브라우저/빌드 설정의 키로 Gemini를 직접 호출했다.
- 서버에 저장된 키는 최소 연결 시험에서 HTTP 200과 텍스트 응답으로 확인했다. 브라우저 저장 키는 추출하거나 복사하지 않았다.
- 통계 분석의 질문 해석·인사이트를 인증된 `dailyReportAnalyticsAi`로 옮겼다. 서버에 저장된 키와 모델을 사용하고, 브라우저의 오래된 키는 이 기능에서 읽지 않는다.
- 기존 일보 조회·집계·팀 범위는 유지한다. 서버 키 조회, 현재 계정 검사, 요청 제한, 오류 안내와 한국 시간 날짜 처리를 검증한다.
- AI 설정 화면은 일보 통계가 서버용 설정을 사용하는 것을 표시하며, 더 이상 적용되지 않는 브라우저 통계 모델 선택기를 제거했다.

구조와 제한은 [서버 키 연결 문서](./daily-report-analytics-server-key.md)를 따른다. 새 AI 업무 도우미의 별도 시범 운영 설정을 변경하는 작업은 아니다.

통계 화면을 새로고침한 뒤 `AI 분석 → 일보 통계`에서 사용할 수 있다. 이 기능을 위해 브라우저의 `gemini_api_key`를 다시 입력할 필요는 없다. 서버 설정은 `/settings/ai`의 서버용 Gemini 설정을 사용한다.

- 브라우저 검사는 자료가 없는 과거 날짜로 진행했다. 실업무 집계 내용이나 개인 자료를 Gemini에 전송하지 않았다.

- 새 AI 업무 도우미의 시범 운영 설정은 변경하지 않았다. 기존의 미지정/꺼짐 상태를 유지한다.
- 기존 서버 함수 전체 배포, 보안 규칙·인덱스 변경, 원격 Git push는 수행하지 않았다.
