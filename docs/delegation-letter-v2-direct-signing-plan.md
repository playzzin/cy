# 작업자 위임장 직접 서명 기획

## 목표

- 기존 관리자 대리서명 흐름을 유지한다.
- 관리자용 `/payroll/delegation-letter-v2`는 기존 관리자 서명 화면으로 유지한다.
- 작업자 메뉴의 별도 페이지에서 로그인한 작업자가 위임장 원문과 본인 정보를 확인한 뒤 직접 동의하고 서명할 수 있게 한다.
- 관리자 또는 작업자가 서명을 수정하면 같은 작업자 서명값을 갱신해 위임장 미리보기와 인쇄본에 즉시 반영한다.

## 화면 흐름

1. 작업자가 작업자 대시보드 또는 작업자 홈에서 `위임장 서명`을 누른다.
2. `/worker/delegation-signature`에서 계정에 연결된 본인 정보만 불러온다.
3. 작업자는 마스킹된 본인 정보와 선지급 사실 및 권한 위임 동의가 명시된 위임장 원문을 확인한다.
4. 명시적 동의 체크 후에만 서명 입력 창을 열 수 있다.
5. 저장이 끝나면 완료 상태를 표시하고 같은 작업자 서명값을 갱신한다.
6. 관리자는 기존 V2 `서명` 탭에서 종전처럼 서명을 등록하거나 수정할 수 있다.

## 데이터 반영

- 서명 이미지는 기존 `workers.signatureUrl`을 사용하므로 기존 출력 로직과 호환된다.
- 작업자 직접 서명에는 `worker_direct` 출처, 동의 시각, 위임장 본문과 문서 맥락 스냅샷을 함께 기록한다.
- 관리자 V2에서 수정한 위임장 본문은 공용 설정에 저장되어 작업자 페이지에서도 같은 내용으로 표시된다.
- 기존 서명이 있는 작업자가 다시 서명하면 새 서명으로 교체되고 화면에 즉시 반영된다.
- 작업자 계정은 연결된 본인 작업자 문서만 조회하며, 서명 관련 필드 외에는 수정할 수 없다.

## 안전장치

- 주민등록번호는 직접 서명 화면에서 뒷자리를 마스킹한다.
- 동의 전에는 서명 버튼을 비활성화한다.
- 기존 서명을 수정하는 경우 교체 사실을 미리 알린다.
- 필압과 획 벡터는 저장하지 않고 결과 이미지만 보관한다.
