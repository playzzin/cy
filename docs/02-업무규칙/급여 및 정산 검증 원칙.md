# 급여 및 정산 검증 원칙

> [!warning] 정책 확정 필요
> 아래 원칙과 실제 구현이 다르면 운영 반영 전에 업무 책임자의 확인을 받는다.

## 공통 원칙

- 실제 CY 월별 원장을 기준으로 한다.
- 급여 행과 원장의 작업자, 연월, 팀, 급여형태를 대조한다.
- 팀 이동자는 해당 월 당시 팀을 기준으로 검증한다.
- 같은 범위의 정정본이 여러 개면 최신 확정본 우선 여부를 명시적으로 확인한다.
- 팀 정보가 없는 레거시 원장을 여러 급여 행에 중복 적용하지 않는다.
- 0원 정정, 감액, 음수 상계도 누락하지 않는다.

## 금액 검증

- [ ] 총공수 × 적용 단가와 산출금액 비교
- [ ] 법인·개인 지급 분리 합계 확인
- [ ] 가불·공제·과태료·기타조정 부호 확인
- [ ] 순공제가 0이어도 상계 구성항목 유지 확인
- [ ] 명세서 금액과 최종 실지급액 비교
- [ ] 화면·Excel·저장 문서 합계 비교

## 금지

- 오래된 화면 캡처나 소스 기본값으로 현재 급여 추정
- 최신성 확인 없이 절대금액이 큰 원장 선택
- 실데이터를 테스트 fixture·로그·문서에 복사
- 검증 없이 운영 급여 확정 또는 일괄 수정
