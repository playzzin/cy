# 매입매출 장부 AI 문서 입력 계획

## 목표

`/payroll/workbook-ledger` 입력폼에서 `/settings/ai`에 저장한 Gemini API Key와 선택 모델을 사용해 세금계산서 PDF/이미지를 분석한다. 사용자는 원본과 추출값을 대조·수정하고, 선택한 행만 입력폼의 빈 행에 반영한 뒤 기존 `DB 등록` 절차로 저장한다.

## 사용자 흐름

1. 입력폼에서 `AI 세금계산서 대량검수`를 선택한다.
2. PDF/JPG/PNG/WEBP/HEIC 파일을 최대 30개 선택한다.
3. Gemini가 파일별 세금계산서를 구조화한다.
4. 원본 미리보기와 추출값을 나란히 보고 회전·대조·수정한다.
5. 날짜, 구분, 거래처, 공급가액, 부가세, 합계, 신뢰도, 기존 DB 중복을 검수한다.
6. 검수 완료 행만 입력폼의 빈 행에 반영한다.
7. 사용자가 입력폼에서 최종 확인 후 `DB 등록`을 실행한다.

## 추출 필드

- 문서: 문서 종류, 작성일자, 승인번호
- 거래처: 공급자/공급받는 자 상호와 사업자번호, 장부 거래처명
- 장부: 매입/매출, 현장명, 품목 요약, 비고
- 금액: 공급가액, 부가세, 합계
- 검수: AI 신뢰도, 판독 경고, 중복 후보

## 검수 규칙

- 입력 차단: 매입/매출·작성일자·거래처 누락, 0원 이하 공급가액/합계, 음수 부가세, 합계 산술 불일치, 현재 입력폼의 자동 부가세 규칙과 불일치
- 수동 확인: 신뢰도 80% 미만, 승인번호/현장명 누락, 흐림·회전·잘림·수정/취소·면세/영세율 등 Gemini 경고
- 중복 확인: `구분 + 작성일자 + 정규화 거래처 + 합계`가 기존 DB 또는 현재 입력폼과 같은 행
- 저장 경계: AI 검수 화면에서는 DB에 쓰지 않고, 입력폼 반영 후 기존 `DB 등록`에서만 저장

## 운영/보안 메모

- 현재 문서 데이터는 사용자가 저장한 브라우저용 Gemini API Key로 Google Gemini API에 직접 전송되며, 장부 DB에는 검수 완료 전 저장하지 않는다.
- 키 오류가 나면 Google AI Studio에서 새 Gemini API 키를 발급하고 `/settings/ai` 상단의 `Gemini API Key`에 저장한다. 이 기능은 `서버 Gemini API Key` 입력란을 사용하지 않는다.
- 장기적으로 조직 공용 키를 사용할 경우에는 Storage 업로드 + 인증된 Cloud Function 분석 작업으로 전환해 브라우저에 공용 키가 노출되지 않게 한다.
- 원본 파일은 현재 세션의 브라우저 메모리 URL로만 미리보기하며 장부 DB나 Storage에 자동 저장하지 않는다.
