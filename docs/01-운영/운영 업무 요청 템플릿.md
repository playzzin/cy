# 운영 업무 요청 템플릿

## 기본 형식

```text
[기간] [대상]의 [할 일]을 [결과물 형식]으로 처리해줘.
[기준 데이터]를 사용하고 [실행 범위]까지만 진행해줘.
```

## 조회

```text
2026년 6월 외부지원간곳 전체 팀의 현장, 공수, 노임, 경비를
CY 실제 데이터로 조회해줘. 데이터는 변경하지 마.
```

## 문서 생성

```text
2026년 6월 안수익팀 외부지원분의 노임명세서와 경비내역서를
CY 실제 데이터와 기존 양식으로 만들어줘.
다른 팀 자료는 제외하고 금액을 검산해줘.
```

## 데이터 변경

```text
[대상]을 [변경값]으로 수정하려고 해.
먼저 대상 건수, 변경 전·후 값과 영향 범위를 dry-run으로 보여줘.
내 승인 전에는 저장하지 마.
```

## 개발

```text
[문제]를 격리 저장소에서 수정하고 테스트까지 완료해줘.
원본·GitHub·운영에는 반영하지 말고 diff와 위험을 먼저 보고해줘.
```

## 실행 범위 표현

- `조회만`
- `파일 생성까지`
- `격리 저장소 수정과 테스트까지`
- `후보 브랜치 push까지`
- `실제 저장 전 승인 요청`
- `배포 금지`
