# 지원 노임명세서 생성 절차

## 원칙

- 인증된 CY 운영 화면을 기준 데이터로 사용한다.
- 방향, 연월, 팀, 현장을 명확히 선택한다.
- CY의 기존 Excel 생성기를 우선 사용한다.
- 전체 파일에서 대상 팀 시트만 남기고 다른 팀의 개인정보는 전달하지 않는다.
- 경비는 노임과 분리하여 표시한다.

## 체크리스트

- [ ] 연월 확인
- [ ] `외부지원간곳` 또는 요청된 방향 확인
- [ ] 대상 팀 확인
- [ ] 현장 수와 현장명 확인
- [ ] 총공수 확인
- [ ] 노임 합계 확인
- [ ] 후청구 경비 건수와 금액 확인
- [ ] CY 원본 Excel 다운로드
- [ ] 대상 팀 시트만 정확한 접미사로 선별
- [ ] 최종 파일 재열기
- [ ] 시트별 공수와 금액 재합산
- [ ] 화면 합계와 파일 합계 비교
- [ ] 민감한 전체 팀 중간 파일 삭제
- [ ] 임시 서버와 브라우저 세션 종료

## 결과 보고 범위

채팅에는 다음 집계만 표시한다.

- 기간
- 대상 팀
- 현장명
- 총공수
- 노임 합계
- 경비 건수와 합계

개인별 주소, 연락처, 계좌, 주민 식별정보는 표시하지 않는다.
