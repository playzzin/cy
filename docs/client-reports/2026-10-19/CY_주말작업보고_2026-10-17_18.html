01

팀장 메뉴가 오른쪽으로 바뀌었습니다

10월 16일 밤 연결 작업 · 팀장 / 반장 / 작업자 / 임대사 / 발주사 / 소개소

운영 반영 확인

PC에서는 업무 메뉴를 화면 오른쪽에 배치했습니다. 휴대전화에서는 오른쪽 위 메뉴 버튼을 누르면 메뉴가 오른쪽에서 펼쳐집니다.

변경 전왼쪽 메뉴
→
변경 후오른쪽 메뉴
  1. 팀장 화면의 오른쪽 위 메뉴 버튼을 누릅니다.
  2. 오른쪽에 열린 목록에서 원하는 업무를 선택합니다.
  3. 닫기 버튼이나 메뉴 밖 영역으로 돌아옵니다.

PC에서 접힌 메뉴의 하위 목록은 화면 안쪽으로 열립니다. 직책 선택창과 메뉴가 겹치는 문제도 함께 수정했습니다.

쉽게 확인하기옆의 설명용 예시에서 메뉴 열기·닫기를 직접 눌러 보세요. 실제 서비스나 업무 데이터와 연결되지 않습니다.

확인 근거: 6개 직책의 오른쪽 배치, 320px·390px·PC의 열기·닫기, 직책 선택창 간격을 검사한 기록과 현재 배포 소스의 우측 배치 설정을 확인했습니다. 각 직책의 실제 계정으로 모든 업무를 검수한 결과는 아닙니다.

02

현장 공수와 지원팀 내역을 더 자세히

대상 · 팀장 / 현장 확인 담당자

기본 조회 반영 · 원본 연결 재반영 필요

담당 현장에서 일한 자기 팀과 지원팀의 공수를 함께 확인하도록 개선했습니다. 참여 팀에서 작업자와 날짜별 내역으로 내려가며 확인할 수 있습니다.

  1. 담당 현장과 조회할 월을 선택합니다.
  2. 참여 팀을 펼쳐 작업자별 내역을 확인합니다.
  3. 날짜를 선택해 그날의 작업량을 확인합니다.
업무에 도움이 되는 점합계만 보고 다시 물어보던 일을 줄이고, 지원 인원까지 포함한 현장 상황을 파악할 수 있습니다.

추가로 완료한 개선: 0.25 같은 소수 공수의 표시를 보완하고, 날짜별 내역에서 원본 일보를 여는 기능도 구현·검증했습니다. 원본 연결과 관련 표시 보완은 앞선 배포 기록에 있으나 현재 운영본에서 재반영 확인이 필요합니다. 지원팀의 급여·계좌 등은 현장 참여 조회에 노출하지 않도록 제한했습니다.

03

메뉴를 나누고, 모바일 이동을 쉽게

대상 · 팀장 / 반장 / 작업자 등 현장 사용자

일부 운영 반영

현장관리를 현장정보와 출력일보로 나누고, 출력일보는 날짜를 선택하는 달력으로 확인하도록 개선했습니다. 인원관리의 근무내역도 별도 메뉴로 분리하는 작업을 완료했습니다.

  • 팀장·반장·작업자의 현황판에는 필요한 탭만 표시합니다.
  • 현장·작업자 목록으로 돌아가는 버튼을 크고 눈에 띄게 바꿨습니다.
  • 현장·파트너 6개 직책의 상단 계산기 버튼을 정리했습니다.
업무에 도움이 되는 점여러 탭을 찾아다니는 대신 필요한 업무로 바로 이동하고, 휴대전화에서 목록으로 돌아가기 쉬워집니다.

대상 · 팀장 / 새로 연결된 팀원

기본 승인 반영 · 후속 보완 재반영 필요

팀장이 같은 팀의 계정을 승인하고, 승인된 작업자가 다시 로그인하는 과정을 점검했습니다. 승인 후 권한을 새로 확인하고, 일시적인 조회 실패 때 불필요한 재가입·재승인 화면으로 이동하지 않도록 보완했습니다.

업무에 도움이 되는 점이미 승인한 사용자가 다시 승인을 요청하는 혼란을 줄이고, 로그인 상태 갱신 중 작성하던 내용을 보호합니다.

사무실 급여를 다른 PC와 함께 보도록

10월 17일 작업 · 사무실 / 급여 담당자

공용 저장·법인세 연동 · 재반영 필요

사무실 급여에 ‘공용 저장’과 ‘공용 자료 다시 불러오기’를 추가했습니다. 저장한 월의 자료를 다른 PC에서 조회하고, 설정된 대상자의 급여를 법인세 비용 집계에 연결합니다.

→
개선월별 공용 저장본
업무에 도움이 되는 점담당자와 PC가 달라도 같은 월의 저장 자료를 기준으로 확인할 수 있습니다.

재반영 후 확인 순서

  1. 사무실 직원급여에서 기준월을 선택합니다.

기존 검수 증거와 이번 보고서 작성 중 확인한 내용을 구분했습니다.

코드 검사부터 모바일 화면까지

아래 결과는 각 작업 당시의 기록입니다. 서로 다른 배포본의 검사 수를 합산해 전체 성과로 표시하지 않았습니다.

✓

자동 검사 기록

주요 변경에서 타입 검사, 코드 규칙 검사, 기능 테스트와 배포용 빌드 통과를 확인했습니다.

✓

PC·모바일 화면 기록

관련 화면을 PC와 모바일 폭에서 검사했습니다. 작은 320px·390px 화면에서도 주요 메뉴와 상세 화면을 확인했습니다.

✓

접근 범위·조회 기록

시험 환경에서 타 팀 접근 제한과 조회 전용 모드의 저장 차단을 확인했습니다. 운영 자료 일부는 조회 전용으로 표본 검수했습니다.

범위 안내: 브라우저 화면 크기 검수는 실제 휴대전화 검수와 다릅니다. 운영 자료 전체 대조, 실제 송금·급여 저장, 모든 사용자 계정의 전체 흐름이 검증된 것은 아닙니다. 기존 자동 검사 중 외부 자료에 의존하는 2개 항목은 제외 기록이 있습니다.

  • 현재 공개 배포 버전 정보를 2026.10.19에 읽어 917ff677을 확인하고 해당 소스와 대조했습니다.
  • 기존 모바일 운영 검수 문서, 현장 지원 공수 배포·브라우저 기록, 법인세·급여 배포 기록을 함께 확인했습니다.
  • 보고서의 도식과 숫자 예시는 설명용으로 구성했습니다. 실제 이름·급여·계좌·로그인 정보는 포함하지 않았습니다.
