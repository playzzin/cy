# 2026-08-31 Phase 1 읽기 전용 무결성 점검 검증

## 결론

격리 후보 `/home/hermes/cy-rebaseline-candidate`에 구현한 Phase 1 무결성 점검기는 코드·테스트·독립 검토 기준을 통과했다. 운영 Firebase에는 접속하지 않았으며, 원본 저장소 수정·Git commit/push·배포도 수행하지 않았다.

## 안전 계약

- 명시적 `--dry-run` 없이는 실행을 거부한다.
- `FIREBASE_PROJECT_ID`가 없거나 Firebase Admin 프로젝트와 다르면 첫 조회 전에 중단한다.
- Firebase Emulator 관련 환경변수가 있으면 중단한다.
- 허용된 10개 컬렉션에 대해 `collection().get()` 읽기만 노출한다.
- 출력은 `checkType`, `count` 두 필드만 허용한다.
- 문서 ID, 작업자·사용자 ID, 이름, 이메일, 회사·현장명, 급여·공제 금액, 해시, salt, 예외 객체를 출력하지 않는다.

## 점검 범위

- 동일 날짜·팀·현장 중복 출력일보 scope
- 빈 작업자 ID 및 live 작업자 마스터에 없는 ID occurrence
- 동일 작업자·월 중복 급여 scope
- 복수 가불 원장, 최신 0원 정정 경쟁, 정정 순서 불확정 scope
- 작업자·팀·현장·회사·사무직·사용자·계정 연결의 고아 참조 occurrence
- account link와 user의 접근범위 불일치 principal
- Firestore 문서 ID와 `legacyId` 충돌
