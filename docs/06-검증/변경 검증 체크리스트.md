# 변경 검증 체크리스트

## 모든 변경

- [ ] 관련 [[../../개발지침|개발지침.md]] 확인
- [ ] 원본 Git 상태 확인
- [ ] 사용자 또는 다른 작업의 변경과 충돌 여부 확인
- [ ] 최소 변경 범위 유지
- [ ] `git diff --check`
- [ ] `NODE_OPTIONS=--max-old-space-size=8192 npm run typecheck`
- [ ] 관련 집중 테스트

## 중요 변경 또는 배포 후보

- [ ] `npm run verify:hosting-build`
- [ ] Firestore Rules Emulator 테스트
- [ ] 실제 업무 산출물 또는 staging 흐름 검수

- [ ] Excel·명세서·저장값 비교
