# 일보 통계 AI의 서버 키 연결

2026-09-28. 일보 통계의 AI 분석에서 브라우저 키 오류가 발생하는 문제를 수정한다.

## 원인과 변경

기존 `geminiAnalyticsService`는 브라우저의 `gemini_api_key` 또는 빌드 환경 값을 우선 사용했고, 서버에 유효한 키가 있어도 이를 사용하지 않았다. 실제 서버 키의 최소 연결 검사는 HTTP 200과 텍스트 응답으로 확인했다. 브라우저 키의 값은 읽거나 복사하지 않았다.

일보 통계의 질문 해석·인사이트 생성을 `dailyReportAnalyticsAi` callable로 옮겼다. 브라우저는 작업 종류와 질문/집계 내용만 보내며, 서버가 `server_settings/ai`의 키와 기본 모델을 사용한다. 키·모델·시스템 프롬프트를 클라이언트가 지정할 수 없다. 키는 [공식 Gemini 인증 헤더](https://ai.google.dev/api)의 `x-goog-api-key`로만 전달하며 URL과 응답·로그에 포함하지 않는다.

기존 통계 계산·데이터 조회는 그대로 유지한다. 이 함수는 원본 업무 자료를 읽거나 수정하지 않으며, 기존 브라우저 조회의 Firestore Rules와 팀 조회 범위를 변경하지 않는다. 질문 해석 프롬프트의 날짜는 한국 시간으로 계산한다. AI 설정 화면은 일보 통계가 서버용 Gemini 설정을 사용하는 것을 표시한다.

## 권한·제한

- 현재 활성 프로필의 업무 역할 또는 팀장 역할을 확인하고, Auth 계정이 중지됐는지 검사한다. 오래된 토큰의 관리자 역할만으로 허용하지 않는다.
- 결과 반환 직전에 현재 권한을 재검사한다. 처리 도중 권한을 잃은 계정에는 결과를 반환하지 않는다.
- 계정별 동시 요청 1개, 분당 12회·한국 날짜 기준 하루 240회를 제한한다. 질문은 4,000자, 인사이트 입력은 32,000자 이하다.
- 요청 제한 문서는 `server_settings/ai/analytics_usage/{uid}`에 보관하며 브라우저 읽기·쓰기를 허용하지 않는다. 질문·집계 내용·키를 이 문서에 저장하지 않는다.
- 키 오류, 권한 오류, 사용량 제한, 모델 오류, 지연을 구분한 안내를 반환한다. 외부 API의 원문 오류는 전달하지 않는다.

새 AI 업무 도우미의 시범 운영 설정은 별도 기능에 적용되며 이 수정으로 변경하지 않는다. 이 수정은 기존 일보 통계 AI 분석의 연결 경로만 바꾼다.

## 검증과 배포

`node scripts/verify-daily-report-analytics-release.cjs`로 타입·전체 앱 테스트·서버 빌드·수정 범위 린트·서버 단위 검사·Auth/Firestore 통합 검사·화면 빌드·배포 파일을 확인한다. 검사 중 소스가 바뀌면 성공 처리하지 않는다.

배포 대상은 `functions:dailyReportAnalyticsAi`와 Hosting이며, 기존 서버 함수·Rules·인덱스를 전체 배포하지 않는다. 배포 전에 현재 운영 버전이 수정 기준과 같은지 확인한다. 배포 후 공개 파일 일치·비로그인 호출 차단과 기존 로그인 세션의 통계 화면 질문을 확인한다. 최종 실행 결과는 후속 운영 반영 기록에 정리한다.
