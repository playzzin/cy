# 대화형 서식 편집

작성일: 2026-09-30

## 변경 내용

후속 요청을 정해진 값 교체 문장으로 제한하던 흐름을 확장했다. Gemini가 현재 시트의 구조·서식·선택 영역과 사용자 요청을 보고 이번 편집을 결정한다. '깔끔하게', '제목을 더 크게', '표를 파란색으로' 같은 요청에서 색상과 크기를 직접 정할 수 있다.

- 글꼴·크기·굵게·기울임·밑줄, 글자색·배경색, 가로·세로 정렬, 줄바꿈, 테두리, 숫자 표시 형식
- 열 너비·행 높이, 내용 손실 없는 병합·병합 해제, 용지 방향·크기·한 페이지 맞춤
- 제목·머리글·공통 문구 변경, 선택한 사람의 값 변경
- 데이터 정렬·필터 등과 서식 변경을 한 요청에서 함께 처리
- 서식 변경 내역 표시, 버전 보관·분기·복원, 원래 서식으로 되돌리기

서식만 바꾸면 데이터 연결 계획을 다시 생성하지 않는다. 선택한 사람의 셀 서식은 원본 행에 연결하므로 정렬 후에도 같은 사람을 따라간다. 서식 되돌리기는 값 변경과 정렬 조건을 유지한다. 원본 양식은 그대로 보관하며 결과 파일에만 변경을 쓴다.

## 검사와 제한

AI에는 문서의 원본 이름·계좌·주소·금액 대신 가린 셀 종류, 알려진 항목명, 좌표와 서식을 전달한다. 값 변경은 기존 작성·재읽기 검사에 포함한다. 요청한 열 너비·병합·인쇄 설정을 보존 검사의 예상값에 반영하며, 나머지 수식·그림·매크로·설정은 계속 검사한다.

수식 재작성과 기존 VBA 모듈 편집은 후속 구현에서 지원한다. 상세 내용과 현재 검증 범위는 [수식·VBA 편집](excel-converter-code-editing.md)을 따른다. 행·열 삽입·삭제와 그림 추가는 아직 지원하지 않는다. 다른 칸의 내용을 가리는 병합은 적용하지 않고 원인을 안내한다. 지원하지 않는 부분을 성공했다고 답하지 않으며, 해당 요청의 이전 완성 결과를 유지한다.

## 검증

- 변환기 및 관련 서비스 테스트 178개 통과. 실제 Excel 수식 정답 사본 대조 포함. 사용자 원본 파일 미지정 조건부 검사 1개 미실행.
- 전체 타입 검사와 수정 범위 린트, 최종 production build 통과. 빌드 전후 코드 일치 검사 및 `build/release.json` 생성 확인.
- 서버 코드 빌드 및 기존 AI 게이트웨이 검사 5개 통과.
- 브라우저에서 제목·색상·원 표시·열 너비 수정, 선택 셀 강조와 주소 수정, 서식 복원 후 값 유지 확인. 서식 AI 응답만 대체했으며 기존 데이터 변환은 실제 서버를 호출했다.
- 390px 모바일에서 가로 넘침 없이 표시됐다. 기기에 보관한 작업을 새로고침 후 열어 결과 4개와 이전 버전의 20pt 제목 서식이 복원되는 것을 확인했다.
- 실제 Microsoft Excel에서 가상 결과를 읽기 전용으로 열어 계산·인쇄 PDF를 확인했다. 수식과 1,270,000원 합계를 유지하며 변경한 서식이 A4 가로 한 페이지에 표시된다. 원본 해시는 변하지 않았다.

## 실제 AI 연결 상태

서식 편집은 기존 서버 공통 기능 `geminiGateway`의 인증·사용량 제한·서버 키 보관 흐름을 재사용한다. 서버 문서 분석 모델 설정을 따른다. 클라이언트에 키를 넣지 않는다.

사용자 승인 후 `functions:geminiGateway` 하나를 배포했다. 실제 Gemini 응답으로 서식·수식·VBA 통합 편집을 확인했다. 위 절의 과거 서식 검사에는 대체 응답이 포함되며, 후속 실제 검사 결과는 [수식·VBA 편집](excel-converter-code-editing.md)에 구분해 기록했다. 배포 근거는 `outputs/excel-converter/edit-validation/deploy-gemini-gateway.log`다.
