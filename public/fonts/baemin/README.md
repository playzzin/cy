# 배달의민족 글꼴

우아한형제들 공식 배포본의 주아체, 도현체, 한나는열한살체를 원본 그대로 포함합니다.

- 배포 페이지: https://www.woowahan.com/fonts
- 원본 패키지: https://woowahan-cdn.woowahan.com/static/fonts/BM-fonts-package.zip
- 저작권: Woowa Brothers Corporation
- 라이선스: SIL Open Font License 1.1 (`LICENSE.txt` 전문 참조)

팀장 직책 화면에만 적용하며 본문은 주아체, 큰 제목은 도현체, 소제목은 한나는열한살체를 사용합니다.
원본 파일은 `src/assets/fonts/baemin`에 있으며, 빌드 시 해시가 붙은 앱 정적 자산으로 배포됩니다.
폰트 파일은 앱과 같은 서버에서 제공하고 `font-display: swap`으로 로딩 중에도 텍스트를 표시합니다.
